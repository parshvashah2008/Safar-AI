# SAFAR AI

Premium travel-planning foundation built with Next.js App Router, React, TypeScript, and provider-ready configuration.

## Current verified scope
Responsive interactive home/discovery experience with destination exploration, prompt-based planner input, save interactions, active itinerary card, demo wallet distinction, and SAFAR Copilot shell. The wallet is explicitly demo mode: no real funds are held and no booking/payment is presented as confirmed.

## Run
`npm install && cp .env.example .env.local && npm run dev`

## Integration status
Gemini, Google Maps, Supabase, translation, Amadeus, payment, and wallet variables are scaffolded but no credentials or provider approvals were available in this empty workspace. No live inventory, money balance, booking, or map is fabricated. An India launch needs an authorized wallet/issuer structure and RBI review. No MCP server configuration was present. Official Maps, Supabase, Duffel, Amadeus, and RBI documentation was read; the Gemini URL was unavailable through the document reader.

## Verification
No build, test, or browser pass is claimed because the workspace had no existing app and npm registry access was not available for dependency installation.
